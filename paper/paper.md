# Summary

`plotly_matlab` is the official Plotly graphing library for MATLAB and GNU Octave.
It converts native figures, created with either engine, into interactive,
web-based charts that can be explored, exported, and embedded in web pages
with a single line of code.

Web-based interactive plots are popular methods of visualizing data which play a core role in scientific research.

![Examples of plots generated by this library in Octave. Top-left shows a quiver plot or vector field plot. Hovering over the field shows the vector values of the field at each location. Top-right shows an ezsurf plot and bottom-left shows a surfc plot. In the case of three dimensional plots like these, the user can spin, pan, and zoom in to change the perspective. Hovering over the surfaces also displays the three dimensional coordinates of the point. Bottom-right shows a simple scatter plot.](front_example.png)

The interactive nature of these plots make them richer in information than plain images because the user can zoom and pan to see finer details and, in the case of three-dimensional plots, they can also rotate and change the perspective of view of those plots. Hovering over data points display tooltips with numerical data, which also make them more informative. Additionally, the web-based nature of these plots make them easier to share between researchers using different operating systems and software, when compared to language specific figure objects.

This library, which was originally created in 2013, builds on top of the existing Plotly library to bring interactive web-based plots to Octave and MATLAB.

# Statement of need

Plotly[@plotly] is widely used by the scientific community to generate interactive web
plots[^1]. While other languages were supported by Plotly, the Octave[@octave] and MATLAB[@matlab] eco-systems, which are widely used in scientific research, both lacked a plotting library that is interactive and web-based.
This library bridges this gap by providing an easy way to generate Plotly figures from the full range
of plots supported by Octave and MATLAB.

[^1]: The canonical citation for Plotly is cited more than 1,000 times on OpenAlex as of Aug 2026 (https://openalex.org/works/W2991157178)

# State of the field

Wrappers for Plotly also exist in R[@r], Python[@python], Rust[@rust], and .NET programming languages[@dotnet].

The Python and R ecosystems have multiple interactive web-visualization options besides Plotly, while Octave and MATLAB users only have this wrapper.

# Software design

The core of the library is the `plotlyfig` class, which walks the graphics
object tree of a figure (figure, axes, and children) and builds a Plotly
figure description (data and layout) through per-class dispatch: a central
`updateData` function routes each graphics object to a dedicated `updateX`
function (one per supported plot type), with shared geometry and color helpers
used across plot types. hggroup-based plot types are resolved through
engine-aware group classification, since MATLAB and GNU Octave expose
different group structures. hggroups are groups of primitive graphics objects (lines, patches, text, etc.).
Three-dimensional scenes are handled explicitly, including camera geometry and
axis aspect-ratio computation derived from each engine's native camera model.

A central design commitment is cross-engine parity. MATLAB and GNU Octave
differ in their graphics object trees (e.g., Octave wraps plot types in
hggroups that MATLAB exposes differently), property semantics (character
arrays versus string types, annotation properties absent in Octave). The library maintains
a single codebase that behaves identically in both engines, with behavior
verified by a regression suite that runs on each.

Testing is an essential part of the project. A test runner
(`runplotlytests`) executes structural regression tests of converted figure
descriptions in both engines, and a gallery of over 80 plot types
(`makegallery`) generates native and converted outputs that are compared by
rendering against a bundled plotly.js in a browser. Continuous
integration runs the Octave test suite on every push (GitHub Actions).

# Research impact statement

`plotly_matlab` is used in published scientific research. For example, it was
used to produce visualizations in a biomechanical imaging study of pelvic
floor ligaments (Matter et al., 2024). The library is distributed through the
official Plotly MATLAB page (plotly.com/matlab) and the MathWorks File
Exchange, is supported on the Plotly community forum, and has been under
active, sustained maintenance since 2024, with regular tagged releases and
extensive issue triage. The project's development history, releases, and
usage statistics are public on GitHub.
